专为**老年人、行动不便长辈及无障碍辅助场景**设计的 Android 微信电话自动化接听模块。

通过底层的 Linux Shell 脚本与系统级硬件事件调度，实现：**微信来电响铃达到指定秒数未接时，全自动点亮屏幕并点击接听**。无需安装额外第三方 App、不常驻重度服务、不耗电、不修改微信安装包、绝无封号风险。

---

## 🌟 核心特性

- ⏱ **秒数自由定制（免重启手机立即生效）**：
  - 自动生成 `/sdcard/微信接听秒数.txt` 配置文件。
  - 默认等待 **3 秒**（方便刷入后立刻拨打测试），日常建议修改为 **15 ~ 20 秒**。
  - **修改文本文件后即时生效**，完全不需要重启手机！
- 🔊 **独创硬件级音频流嗅探（100% 穿透系统限制）**：
  - 彻底攻克各大厂商定制系统（ColorOS、MIUI/HyperOS、OriginOS、EMUI 等）将通知脱敏加密为 `vis=PRIVATE` 导致无法被软件识别的行业痛点；
  - 只要微信播放来电响铃（`USAGE_NOTIFICATION_RINGTONE`），系统底层硬件在第 1 毫秒瞬间捕获！
- 📱 **双形态来电自适应识别**：
  - **全屏大界面（锁屏/桌面来电）**：不论是语音还是视频通话，精准点击右下角绿色接听大圆圈；
  - **顶部悬浮小卡片（长辈正在微信聊天中来电）**：精准定位并点击右上角卡片绿色接听键；
  - 无论是新版微信去掉了“接听”文字的纯图标界面，还是老版带字界面，通通秒级自适应！
- 🛡 **三重防误触与主叫免疫保护**：
  - **主动拨打保护**：长辈主动给子女或亲友拨打电话时，识别到主叫状态，**绝对不动作、不计时、安全退出**；
  - **通话中绝对锁定**：接通电话后进入通话保护，通话期间（哪怕聊一小时）**坚决不碰屏幕任何位置**，防止连击误挂；
  - **已接听/已挂断自检**：在等待时间内，若长辈已自行接听、或对方中途取消呼叫，脚本自动放弃，不乱点屏幕。
- ⚡ **单次生命周期（Run-Once）纯净架构**：
  - 杜绝传统死循环轮询，来电时拉起单次任务，接通后进程彻底退出（`exit 0`）。
  - 平时待机 **CPU 占用 0.0%**，内存开销 **< 2.5MB**。

## 🚀 安装指南

### 1. 前置条件
- 手机已获取 Root 权限（支持 **Magisk**、**KernelSU**、**APatch**）；
- 建议将长辈手机的锁屏方式设置为**“无密码”**或**“滑动解锁”**（若设置了复杂的数字/图案密码，熄屏状态下 Android 系统级安全策略会拦截点击事件）。

### 2. 刷入步骤
1. 前往本项目的 [Releases](../../releases) 页面，下载最新的 `WeChat_AutoAnswer_Magisk.zip`；
2. 打开手机上的 **Magisk App**（或 KernelSU / APatch 管理器）；
3. 进入 **「模块」 (Modules)** 界面，点击 **「从本地安装」**；
4. 选择下载的 `WeChat_AutoAnswer_Magisk.zip`，刷入完成后点击 **重启手机**。

## ⚙️ 个性化配置（修改接听秒数）

模块刷入后，手机存储根目录会自动生成配置文件：
📄 **`/sdcard/微信接听秒数.txt`**

```txt
3
```

* **初始默认值**：`3`（方便您刚刷入后用另一部手机打过来快速测试）；
* **长辈日常推荐**：测试通过后，请使用手机自带的“文件管理”或“MT管理器”打开该文件，把数字改成 **`15`** 或 **`20`** 并保存；
* **即改即生效**：脚本在每次来电时动态读取该文件，**修改后完全无需重启手机**！

## 🛠 工作原理架构

```mermaid
flowchart TD
    A[来电到达: 微信播放 USAGE_NOTIFICATION_RINGTONE] --> B[底层调度器 service.sh 瞬间捕获]
    B --> C[拉起单次生命周期接听程序 answer_once.sh]
    
    C --> D[读取 /sdcard/微信接听秒数.txt 缓冲等待]
    D --> E{长辈是否已自行接听 / 对方已挂断?}
    E -->|是| F[安静退出, 绝不触碰屏幕]
    
    E -->|否 (满设定秒数未接)| G{检查通话形态}
    G -->|形态 A: 全屏来电大界面| H[精准点击右下角绿色接听大圆圈 (864, 1965)]
    G -->|形态 B: 顶部悬浮小卡片| I[精准点击右上角卡片绿色接听键 (924, 408)]
    
    H --> J[指令下达, answer_once.sh 进程彻底退出 (exit 0)]
    I --> J
    J --> K[进入通话中保护锁定: 通话期间绝不再触发任何点击]
    K -->|用户挂断电话| L[解除锁定, 恢复待命]
```

## 💡 常见问题 (FAQ)

#### Q1：长辈主动给别人打电话，会被误点击或者挂断吗？
**答：绝对不会。** 脚本内置主叫免疫拦截，当长辈主动呼叫他人时，界面呈现“正在等待对方接受邀请”且按钮为单个“取消”，脚本会准确识别为主叫状态，直接安全退出，绝不执行点击。

#### Q2：支持在没有 Magisk 的情况下单次调用吗？
**答：支持！** 模块内置了纯净的单次脚本 `answer_once.sh`。如果你使用 **Tasker** 或 **MacroDroid** 等自动化软件，可以直接配置触发器并在来电时执行：
```sh
su -c 'sh /data/adb/modules/wechat_auto_answer/answer_once.sh'
```
跑完一次生命周期自动退出，无需后台常驻。

#### Q3：会造成微信封号吗？
**答：绝对不会。** 本模块属于系统级无障碍模拟辅助（调用 Android 官方底层的 `input tap`），既没有注入微信进程，也没有 Hook 微信内部方法，在微信服务器看来就是长辈的手指按了一下屏幕，属于纯天然行为。
